Introduction

      The rapid growth of cloud-assisted Internet of Things (IoT) systems has led to the generation and storage of large volumes of sensitive data such as healthcare records, industrial logs, and smart environment information. Due to limited storage and processing capabilities of IoT devices, cloud servers are widely used for data storage and management. Although encrypting data before outsourcing ensures confidentiality, it introduces significant challenges in terms of efficient data search, fine-grained access control, and secure data deletion. Traditional encryption schemes do not support keyword-based search on encrypted data, while existing searchable encryption techniques often lack flexible access control and forward security. Moreover, secure deletion of cloud-stored data is difficult, as cloud servers cannot be fully trusted to permanently remove data once it is deleted The proposed system integrates attribute-based encryption with searchable encryption to enable fine-grained access control and secure keyword search over encrypted data. In addition, a puncturable encryption mechanism is incorporated to achieve self-controlled and forward-secure data deletion. Using this mechanism, the data owner can invalidate the search capability for specific encrypted data by puncturing the trapdoor with selected labels, without relying on the cloud server or any trusted third party. The proposed Pun-CP-ABSE scheme ensures forward security, meaning that once data is deleted, neither past nor future search queries can retrieve the deleted data. Overall, this project provides a secure, flexible, and efficient solution for encrypted data storage, retrieval, and permanent deletion in cloud-based IoT systems.
